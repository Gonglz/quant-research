# Research Template

Use one directory per research question. Keep the scope narrow enough that the question can be answered or rejected with a small number of experiments.

## Required sections

### Question
What exactly are we trying to learn?

### Mechanism
What causal or economic mechanism could generate the effect?

### Hypothesis
State a falsifiable expectation before inspecting the final result.

### Data required
List the variables, frequency, date range, and required point-in-time semantics.

### Method
Describe the smallest useful empirical test first. Add complexity only when the simple test fails for a known reason.

### Result
Record what the evidence actually showed, including null or contradictory results.

### Limitations
Record confounders, sample limitations, regime dependence, measurement problems, and model risk.

### Next questions
What should be tested next?

### Promotion / data request
Choose one:

- `none`: research-only finding.
- `data_request`: Quant-v2 lacks a required trustworthy base dataset.
- `public_feature`: stable reusable transformation candidate.
- `factor_candidate`: economically motivated signal that merits broader validation.

Do not promote a feature merely because one backtest looks good.
